使用教程

从安装到用熟每一个手势。大约十分钟读完；不想读完的话，看完「第一次使用」和「手势一览」就能上手。

开始之前

GlideShell 需要：

  • Windows 11（在 24H2 上开发与验证，暂不支持 Windows 10）。
  • 精确式触摸板：打开 Windows「设置 → 蓝牙和其他设备 → 触摸板」，页面顶部写着「你的电脑具有精确式触摸板」就可以用。近几年的笔记本几乎都是。

GlideShell 只接管它实现了的几个多指手势；双指滚动、缩放、三指轻点（中键）这些照旧由 Windows 处理。

安装与升级

  1. 打开 GitHub Releases，下载 GlideShell-版本号-win-x64.zip。
  2. 解压到任意位置，双击里面的 安装.cmd。
  3. 装好后程序会自动启动，托盘（任务栏右下角）出现 GlideShell 图标。

程序装在 %LOCALAPPDATA%\Programs\GlideShell，会添加开始菜单和开机启动，全程不需要管理员权限。

程序还没有正式的代码签名，第一次运行时 Windows 可能提示「Windows 已保护你的电脑」或「无法验证发布者」。点更多信息 → 仍要运行即可。GlideShell 完全开源，也可以自己从源码构建。

升级：下载新版本后同样双击「安装.cmd」。正在运行的 GlideShell 会先正常退出再被替换，你的设置会保留。

第一次使用

装好后什么都不用设，直接试：

  1. 在触摸板上三根手指往上滑：所有窗口跟着手指平铺开，这就是窗口总览。
  2. 滑到一半停住：画面也停在半路。往回滑：画面就倒退。
  3. 松手：滑过一半或滑得够快就展开，否则收回去。
  4. 展开后点一个窗口，它会飞回原位并切到前台。

托盘图标：左键单击打开 / 收起窗口总览；右键菜单里可以打开设置、暂停（立即交还 Windows 原生手势）、切换灵敏度、退出。

再次从开始菜单启动 GlideShell，会直接打开设置窗口。

下滑：只看当前程序的窗口
三指左右滑在窗口之间切换
四指上下滑下滑：显示桌面
上滑：拉回窗口 / 打开总览
四指左右滑切换虚拟桌面
手势默认开启「三指拖移」后
三指上 / 下滑上滑总览，下滑应用窗口视图按住左键拖动
三指左 / 右滑切换窗口按住左键拖动
四指上 / 下滑下滑显示桌面，上滑拉回窗口（桌面没显示时打开总览）窗口总览
四指左 / 右滑切换虚拟桌面切换虚拟桌面
三指轻点Windows 默认（中键）

所有手势都跟手：画面位置由手指位置决定，可以停住、可以往回；松手时按「滑了多远 + 滑得多快」决定完成还是取消，就像 Mac 一样。每个手势做什么都可以在设置里改，也可以选「系统默认」交还给 Windows。

窗口总览

打开：三指上滑；也可以单击托盘图标、按 Ctrl + Alt + O，或者用触发角、鼠标手势。

收起：三指下滑（同样跟手），或按 Esc，或点空白处。

选一个窗口

  • 直接点窗口；或者鼠标停在窗口上（出现蓝色框）后三指下滑、按 Enter。
  • 三指左右滑、方向键、Tab / Shift+Tab 都能移动选中项。
  • 收起时被选中的窗口会先飞回原位、略微放大，提示它将成为前台窗口。

关闭窗口

鼠标停在窗口上，左上角出现「×」，点它关闭窗口，其余窗口自动补位。程序弹出「是否保存」之类的对话框时，总览会收起并切到它，让你看到它在问什么。

只看某个程序的窗口

点窗口下面的标题行（程序图标 + 标题），总览会换成只显示这个程序窗口的应用窗口视图；再点一次标题行换回来，都不用收起。

桌面条与多桌面

有两个以上虚拟桌面时，总览顶部会显示桌面条：

  • 切换桌面：把指针移到顶部，桌面名展开成实时缩略图；点另一个桌面，它会放大进入并切过去。
  • 移动窗口：按住一个窗口拖到顶部某个桌面上松开，窗口就移到那个桌面；拖到「+」上会新建一个桌面并移过去。
  • 新建桌面：点桌面条末尾的「+」。
  • 删除桌面：指针停在某个桌面上，名字右边出现「×」，点它删除；上面的窗口会并入相邻的桌面。
  • 翻页：在总览里四指左右滑，会留在总览里、横向滑到相邻桌面的那一页（各桌面的窗口都已排好）。

应用窗口视图

没打开总览时三指下滑：只把当前程序的窗口平铺出来（类似 Mac 的 App Exposé），最小化的窗口单独排在底部一排，其他程序的窗口原地淡出。三指上滑收起，点窗口切过去。

不需要这个功能的话，可以在「设置 → 总览与桌面」里关掉「只看当前程序的窗口」。

显示桌面

四指下滑：所有窗口跟着手指滑出屏幕边缘，露出桌面。四指上滑：窗口从屏幕外滑回原位，上下层次和原来一样。

桌面没有处于「显示桌面」状态时，四指上滑会打开窗口总览（和 Mac 一样）。

显示桌面其实会把窗口最小化，所以从任务栏也能把它们一个个点回来。以管理员身份运行的程序，GlideShell 没有权限把它推开。

切换窗口（三指左右滑 / Alt+Tab）

三指左右滑，屏幕中央出现一排窗口缩略图，跟着手指平移，居中的那个带蓝色选中框。松手后选中的窗口从切换条飞回它的位置并切到前台。往回滑到最开始的窗口再松手，就什么也不切换。

总览已经打开时，三指左右滑改为在总览里移动选中项。

Alt+Tab

键盘的 Alt + Tab 也换成了同一个切换条：

  • 按住 Alt，每按一次 Tab 选下一个窗口（Shift + Tab 选上一个，← → 也可以，到头会绕回来）。
  • 松开 Alt：选中的窗口从切换条飞回它的位置并切到前台。按 Esc 取消，Enter 立即切换。
  • 快速按一下 Alt+Tab：直接切回上一个窗口，切换条不会出现（和 Windows 一样）。

暂停、排除的程序在前台或全屏暂停时，Alt+Tab 仍是 Windows 自己的。不想要的话在「设置 → 总览与桌面 → 键盘」里关掉。

切换桌面（四指左右滑）

四指左右滑，相邻的桌面跟着手指滑进来；滑过一半或滑得够快就切过去。没有相邻桌面时会有橡皮筋回弹。

键盘 Ctrl + Win + ← / → 也使用同样的跟手动画（连按会接着切）；总览开着时改为在总览里翻页。不喜欢的话可以在设置里关掉，交还 Windows。

鼠标按键手势

不用触摸板时，也可以用鼠标做同样的事（灵感来自 Mac 上的 Mac Mouse Fix）。按住鼠标侧键「后退」拖动：

  • 左右拖：切换桌面，桌面跟着指针走（拖过一个屏幕宽正好切一个桌面）。
  • 往上拖：打开窗口总览。
  • 往下拖：只看当前程序的窗口；总览开着时则是收起。

只是点一下侧键（没有拖动）时，它仍然是原来的「后退」。在「设置 → 鼠标与触发角」里可以改成「前进」键或中键、调灵敏度，或者关掉。

触发角

把指针移到屏幕的某个角上停一下（约 0.1 秒），就触发设定的动作：窗口总览、应用窗口或显示桌面。默认都没开。

在「设置 → 鼠标与触发角」的屏幕示意图上，点四个角上的按钮来选择。全屏、暂停或排除的程序在前台时不会触发。

设置

托盘图标右键 → 设置…，或者再次从开始菜单启动 GlideShell。改动立即生效，不用点保存。

进阶：配置文件

弹簧参数等不常用的选项在配置文件 %APPDATA%\GlideShell\config.json 里（可以带注释，保存后立即生效）。每一项的说明见 配置参考。

排除程序与暂停

  • 排除的程序：远程桌面、虚拟机、自己处理手势的游戏或绘图软件在前台时，你可能更想用 Windows 自己的手势。在「设置 → 排除的程序」里添加它们（可以从正在运行的程序里选，或者输入进程名，例如远程桌面是 mstsc）。
  • 全屏时暂停：默认开启，游戏、视频、演示全屏时不接管手势。
  • 临时暂停：托盘右键 → 暂停，立即交还所有 Windows 原生手势；再点一次恢复。

常见问题

手势没有反应

  • 确认是精确式触摸板（见开始之前）。
  • 托盘图标右键，看看是不是处于「暂停」状态。
  • 当前前台程序是否在「排除的程序」里，或者是否全屏。
  • 那个手势在设置里是不是被设成了「系统默认」。

退出后系统手势没有恢复

正常情况下退出、暂停、卸载，甚至程序意外崩溃时都会自动还原。万一没有，运行：

"%LOCALAPPDATA%\Programs\GlideShell\GlideShell.exe" --restore-native

总览盖不住开始菜单、某些窗口切不到前台

发布包是普通权限版，覆盖层排在系统界面（开始菜单、通知中心）下面，以管理员身份运行的程序也不能被它切到前台或最小化。需要的话可以按 README 从源码构建 UIAccess 版。

切换桌面时屏幕底部出现桌面名

这是 Windows 自己画的提示，目前没有办法从外部隐藏。

想反馈问题

托盘右键 → 打开日志目录，把 glideshell.log 附在 GitHub Issues 里，并说明你的笔记本型号与 Windows 版本。日志只保存在本机，GlideShell 不联网。

卸载

双击安装包里的 卸载.cmd。它会先让 GlideShell 正常退出、确认系统手势已经还原，再删除程序、开始菜单和开机启动。

你的设置（%APPDATA%\GlideShell）和日志会保留，方便以后重装；想连它们一起删除，运行 uninstall.ps1 -Purge。
