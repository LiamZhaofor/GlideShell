为什么是 GlideShell

手势应该是「推着走」，不是「按开关」

Windows 原生的多指手势大多是识别到手势就播放一段固定动画；GlideShell 直接读取触摸板的原始触点，画面的每一帧都由手指位置决定。

Windows 原生

识别到手势 → 播放固定动画。手指停住、往回滑，动画都不理会。

● 手指■ 画面

GlideShell

画面 1:1 跟着手指；停住就停住，往回就倒退，松手速度直接传给弹簧动画。

● 手指■ 画面
功能

一整套 macOS 式的多任务

所有手势都跟手，所有动画都能随时被新手势接住。

窗口总览

三指上滑，每个窗口从原位飞向平铺位置；窗口下方是程序图标和标题，悬停出现关闭按钮。

桌面条与多桌面

总览顶部列出所有虚拟桌面：点一下切过去，把窗口拖上去就移过去，「+」新建、「×」删除。

应用窗口视图

三指下滑只看当前程序的窗口（App Exposé），最小化的单独排一排；在总览里点标题也能直接切换过去。

四指切换桌面

相邻桌面跟着手指滑入，没有起滑死区，首尾有橡皮筋；Ctrl+Win+←/→ 也用同样的动画。

三指切换窗口

三指左右滑，窗口条随手指平移；松手后选中的窗口从切换条飞回原位，再切到前台。Alt+Tab 也换成了同一个切换条。

显示桌面

四指下滑，窗口跟着手指滑出屏幕边缘露出桌面；再四指上滑，按原来的层次拉回来。

鼠标也能跟手 新

像 Mac Mouse Fix 一样，按住鼠标侧键拖动：左右切换桌面、上拉总览、下拉应用窗口。只点一下仍是「后退」。

macOS 式物理

松手按距离和速度决定去留，速度直接传给弹簧；越界有橡皮筋；动画随时能被新手势接住。

精致的细节 新

与系统一致的窗口阴影、随窗口缩放的圆角卡片、毛玻璃桌面条；撤掉覆盖层那一刻与真实桌面无缝衔接。

触发角

把屏幕四个角设成窗口总览、应用窗口或显示桌面，指针停在角上就触发。

Windows 11 风格设置 新

Mica 背景、圆角卡片，跟随系统深浅色；每个选项都有一句白话说明，改动立即生效。

轻量、可退回

不装驱动，约 5.6MB 的原生程序；退出、暂停或意外崩溃时，自动把系统手势还原成你原来的设置。

手势

四个方向，覆盖日常多任务

每个手势都可以在设置里改，或者交还给 Windows。三指轻点（中键）始终由系统处理。

三指上下滑

上滑打开窗口总览；下滑只看当前程序的窗口。

三指左右滑

在窗口之间切换，松手切过去。

四指上下滑

下滑显示桌面；上滑把窗口拉回来。

四指左右滑

切换虚拟桌面，桌面跟着手指走。

下载

一分钟装好

不需要管理员权限，不装驱动；卸载时自动还原系统手势。

  1. 下载最新版从 GitHub Releases 下载 GlideShell-版本号-win-x64.zip。
  2. 解压后双击「安装.cmd」程序装到你的用户目录，并添加开始菜单与开机启动。
  3. 用三指往上滑窗口总览就会跟着手指展开。托盘图标右键可以打开设置。

系统要求

  • Windows 11（在 24H2 上开发与验证）
  • 精确式触摸板（大多数近几年的笔记本都是）
  • 鼠标手势：带侧键或中键的鼠标（可选）

程序还没有正式签名，第一次运行时 Windows 可能提示「无法验证发布者」，选「更多信息 → 仍要运行」即可。完全开源，可以自己从源码构建。

常见问题

还有疑问？

怎么知道我的触摸板是不是「精确式触摸板」？

打开 Windows「设置 → 蓝牙和其他设备 → 触摸板」，如果页面顶部写着「你的电脑具有精确式触摸板」就可以用。

会不会弄乱我原来的手势设置？

不会。GlideShell 只接管它实现了的手势，接管前会先把你原来的设置记下来；退出、暂停、卸载，甚至程序意外崩溃时，都会自动还原。万一没有还原，运行 GlideShell.exe --restore-native 即可。

某个程序里我想用 Windows 自己的手势怎么办？

在设置的「排除的程序」里加上它，这个程序在前台时 GlideShell 就不接管手势。全屏游戏、视频默认也不接管。

支持 Windows 10 吗？

暂时不支持。GlideShell 用到了 Windows 11 才有的合成器接口。

收费吗？会收集数据吗？

完全免费、开源（MIT 许可）。不联网，不收集任何数据；日志只保存在本机。
