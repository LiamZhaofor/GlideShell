# GlideShell 配置参考

配置文件：`%APPDATA%\GlideShell\config.json`（托盘「打开配置文件（高级设置）」）。

- 第一次启动时自动生成，字段名为小驼峰，枚举值为字符串。
- **保存即生效**：GlideShell 监视这个文件，改动后自动重载，不需要重启。
- 可以写 `//` 注释、末尾逗号；缺失的字段取默认值；不认识的字段忽略。
- 数值越界会被夹回合法范围；文件格式错误时整体退回默认配置。两种情况都写进日志（托盘「打开日志目录」）。
- 托盘里的开关（三指拖移、四指切桌面、灵敏度、不使用手势的程序、全屏时暂停）改的也是这个文件；通过托盘改设置时整个文件会重写，手写的注释会丢失。

所有距离都是**手指在触摸板上移动的毫米数**，与触摸板分辨率、屏幕大小无关。

## 顶层

| 字段 | 默认 | 说明 |
|---|---|---|
| `threeFingerDrag` | `false` | 三指拖移：三指滑动 = 按住左键拖动。开启后三指整组让给拖移，总览改为四指上下、切换窗口没有手势（同 macOS）。三指轻点（中键）不受影响 |
| `excludedProcesses` | `[]` | 前台是这些程序时不接管手势（进程名，不含 `.exe`，不区分大小写），例如 `["mstsc", "vmware"]` |
| `pauseInFullscreen` | `true` | 前台是全屏程序（游戏、演示、视频）时不接管手势 |
| `hotCorners` | 都是 `None` | 触发角，见下文 |
| `mouse` | 后退键 | 鼠标按键手势（按住拖动），见下文 |
| `bindings` | 不填 | 自定义手势映射，见下文；不填时按 `threeFingerDrag` 取默认映射 |

## 手势映射 `bindings`

每条绑定：几根手指（3–5）、沿哪个方向（`Vertical` 上下 / `Horizontal` 左右）→ 哪个动作。

| 动作 | 说明 | 可用方向 |
|---|---|---|
| `Overview` | 窗口总览：上滑（或右滑）展开、反向收起，全程跟手 | 上下、左右 |
| `SwitchWindows` | 跟手切换窗口 | 左右 |
| `SwitchDesktops` | 连续切换虚拟桌面 | 左右 |
| `Drag` | 三指拖移 | 只能三指 |
| `ShowDesktop` | 显示桌面：下滑把窗口推出屏幕并最小化；桌面已显示时上滑拉回，否则上滑打开窗口总览。默认绑在四指上下 | 上下 |
| `None` | 不接管，留给系统 | — |

**没有绑定的手势一律留给 Windows**（例如默认映射下的四指上下，仍是系统的任务视图 / 显示桌面）。GlideShell 只关闭被它接管的那几个系统手势，退出、暂停或崩溃时都会还原成你原来的设置。

默认映射（`threeFingerDrag: false`）：

```jsonc
"bindings": [
  { "fingers": 3, "axis": "Vertical",   "action": "Overview" },
  { "fingers": 3, "axis": "Horizontal", "action": "SwitchWindows" },
  { "fingers": 4, "axis": "Horizontal", "action": "SwitchDesktops" }
]
```

例：三指留给系统、全部功能改用四指——

```jsonc
"bindings": [
  { "fingers": 4, "axis": "Vertical",   "action": "Overview" },
  { "fingers": 4, "axis": "Horizontal", "action": "SwitchWindows" }
]
```

（这样切桌面没有手势；Windows 原生的四指切桌面会被 `SwitchWindows` 接管掉。）

映射有冲突时（同一指数和方向绑了两个动作、开启三指拖移后三指又绑了别的、切换动作绑在上下方向等）整张映射作废、退回默认映射，并写日志。

## 识别 `recognition`（灵敏度）

| 字段 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `slopMm` | 2 | 0.5–20 | 手指移动超过它才算开始滑动。小 = 起步更灵敏，太小会把轻点的抖动当成滑动 |
| `fingerSettleMs` | 60 | 0–200 | 指数变化后要稳定这么久才确定是几指（手指很难同时落下）。移动很快时不等 |
| `tapMaxDurationMs` | 200 | 50–1000 | 轻点：按下到抬起不超过这么久 |
| `tapMaxMoveMm` | 1 | 0–slopMm | 轻点：期间移动不超过这个距离 |
| `axisLockRatio` | 1 | 0.25–4 | 方向判定：左右位移 ≥ 上下位移 × 它 判为左右。1 = 以 45° 为界；调大则更容易判为上下 |
| `velocityWindowMs` | 100 | 20–300 | 松手速度按最后这么久的轨迹估计 |
| `minFingers` | 3 | 3–5 | 参与识别的最少指数（1–2 指始终归系统） |
| `staleTimeoutMs` | 10000 | 1000–60000 | 异常恢复：手势进行中这么久收不到任何触摸板报文才取消（设备被拔出等）。不是松手判定 |

托盘里的「灵敏度」同时调整 `slopMm` 和下面各功能的行程：

| 预设 | slopMm | overview.travelMm | switcher.mmPerWindow | desktops.travelMm |
|---|---|---|---|---|
| 高 | 1.5 | 24 | 18 | 45 |
| 标准 | 2 | 30 | 22 | 55 |
| 低 | 3 | 38 | 28 | 68 |

手动改过、不属于任何预设时，托盘显示「灵敏度：自定义」。

## 总览 `overview`

| 字段 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `travelMm` | 30 | 5–100 | 滑动多少毫米完全展开 |
| `backdropDim` | 0.6 | 0–1 | 展开后背景（壁纸）变暗的程度，0 = 不变暗 |
| `primaryMonitorOnly` | `false` | — | 多显示器时只在主显示器上展开总览 |
| `sharedThumbnails` | `true` | — | 用共享缩略图视觉（未公开的 dwmapi#147 + DirectComposition）代替经典 DWM 缩略图：高刷新率屏幕上明显更流畅，并能画出与系统一致的窗口阴影（撤层前后画面一致）。总览与四指切桌面都用它；系统不支持或出错时自动退回经典缩略图（没有阴影，日志里有记录）。设置窗口「外观」里也能开关 |
| `groupByApp` | `false` | — | 总览里同一个程序的窗口排在一起（默认按窗口原来的位置就近排） |
| `cornerRadius` | 12 | 0–24 | 窗口卡片的圆角（DIP）。窗口从原位飞到平铺位的途中，圆角从窗口自己的（Windows 11 是 8，最大化的窗口是 0）过渡到这个值，收起时再过渡回去，撤层前后画面一致。桌面条里的桌面缩略图取它的 0.6 倍，三指切换条的缩略图同样用它。0 = 保持窗口原样 |
| `appWindows` | `true` | — | 收起态下沿收起方向滑（默认三指下滑）打开应用窗口视图：只平铺当前程序的窗口，其他窗口原地淡出（macOS App Exposé）；向上滑收起。关掉后这个方向不做任何事 |
| `spring` | 0.35 / 0.86 | — | 松手后的弹簧，见下文 |

## 切换窗口 `switcher`

| 字段 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `mmPerWindow` | 22 | 5–100 | 横滑多少毫米切过一个窗口 |
| `spring` | 0.3 / 0.9 | — | 松手吸附到窗口的弹簧 |

## 切换虚拟桌面 `desktops`

| 字段 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `enabled` | `true` | — | 由 GlideShell 接管四指横滑。关掉后交还 Windows 原生切桌面（原生本身也跟手，只是没有松手速度与弹簧）。虚拟桌面接口自检不通过时自动视为关闭 |
| `travelMm` | 55 | 10–150 | 横滑多少毫米整整切过一个桌面 |
| `takeOverHotkeys` | `true` | — | Ctrl+Win+←/→ 也用 GlideShell 的切桌面动画（替代系统动画，连按会接着切）；总览展开时改为在总览里翻页。随 `enabled` 一起生效 |
| `spring` | 0.32 / 0.92 | — | 松手后的弹簧 |

## 触发角 `hotCorners`

指针停在屏幕某个角上（两块屏相接、指针会滑过去的角不算）超过 `dwellMs` 就触发一次，离开角落一段距离后才能再触发。按着鼠标键时、暂停时、排除的程序或全屏程序在前台时不触发。

| 字段 | 默认 | 说明 |
|---|---|---|
| `topLeft` / `topRight` / `bottomLeft` / `bottomRight` | `None` | `None`、`Overview`（窗口总览，开着时收起）、`AppWindows`（应用窗口视图）、`ShowDesktop`（显示桌面，已显示时拉回） |
| `dwellMs` | 100 | 0–2000，指针在角上停多久才触发 |

## 鼠标按键手势 `mouse`

按住一个鼠标键拖动，像在触摸板上滑一样跟手（Mac Mouse Fix 的「调度中心与空间」）：左右切换虚拟桌面（总览开着时在总览里翻页），上拉打开总览，下拉在收起态打开应用窗口视图、在总览里收起。指针照常移动；拖动距离取鼠标的原始位移（不带指针加速，指针到了屏幕边上也照样算），与 Mac Mouse Fix 一样。没拖开（不到 7 像素）就松开，照常是这个键原来的功能（后退 / 前进 / 中键）。暂停、排除的程序或全屏程序在前台时不拦截。

| 字段 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `button` | `Back` | — | `None`（不用）、`Back`（侧键后退）、`Forward`（侧键前进）、`Middle`（中键） |
| `sensitivity` | 1 | 0.25–4 | 灵敏度倍数。1 = Mac Mouse Fix 的手感：横向拖过一个屏宽切过一个桌面（桌面跟着指针走），竖向拖过半个屏高完全展开总览；松手时按速度决定，不用拖满 |

## 三指拖移 `drag`

| 字段 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `pixelsPerMm` | 14 | 1–80 | 慢速时手指每移动 1 毫米，指针移动多少物理像素 |
| `acceleration` | 0.6 | 0–4 | 速度加速：手指速度 100mm/s 时增益乘以 (1 + 它)，最多按 400mm/s 计。0 = 不加速 |

## 弹簧 `spring`

松手后画面以松手时的速度为初速度、用阻尼弹簧落到目标（展开 / 收起、某个窗口、某个桌面），动画中可以随时被新手势接住。

| 字段 | 范围 | 说明 |
|---|---|---|
| `response` | 0.05–2 | 弹簧周期（秒）。小 = 更快更硬 |
| `dampingRatio` | 0.1–3 | 阻尼比。1 = 刚好不回弹；小于 1 有回弹（越小弹得越多）；大于 1 更「黏」 |
