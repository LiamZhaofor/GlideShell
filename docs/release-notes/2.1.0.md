2.1 的主题是「不只给中文用户」：GlideShell 的界面、安装包和官网都有了英文版。

## 英文界面

- 设置窗口、托盘菜单、通知、诊断页与诊断报告都有简体中文和英文两套。
- 默认跟随 Windows 的显示语言：系统是中文就显示中文，其他语言一律显示英文。
- 也可以在「设置 → 首页 → 语言 / Language」里手动切换，切换后立即生效，不用重启。配置文件里对应 `language`（`auto` / `zh-CN` / `en`）。
- 日志始终是中文。

## 新的安装包

- 双击入口改为 `Install.cmd`、`Uninstall.cmd`，说明文件改为中英双语的 `README.txt`。纯英文文件名在任何解压工具里都不会乱码。
- 安装、卸载时的提示按系统语言显示。
- 修正：卸载脚本以前不管开始菜单快捷方式指向哪里都会删除；现在只删指向被卸载的那份程序的快捷方式。

## 官网与教程

- 官网和使用教程有了英文版：<https://liamzhaofor.github.io/GlideShell/en/>，导航栏右上角可以切换语言。

## 其他

- 设置页里「三指轻点始终由 Windows 处理」的过时说明已删掉（从 1.6.2 起三指轻点由 GlideShell 处理）。
- 反馈问题更方便：GitHub 上新增了「问题反馈」「触摸板兼容报告」模板。用的不是 ASUS 触摸板的话，欢迎提一份兼容报告，不管好不好用。
- 每次提交都会在 GitHub 上自动编译并跑全部测试，发版也改成了自动打包。

## 安装与升级

- 已装 2.0.0 的：点托盘的升级通知或「设置 → 关于 → 升级」，一键升级，设置保留。
- 新安装：下载 `GlideShell-2.1.0-win-x64.zip`，解压后双击 `Install.cmd`（不需要管理员权限）。
- 完整的使用教程：<https://liamzhaofor.github.io/GlideShell/guide.html>

## 已知限制

- 只在一台机器上完整验证过（ASUS 精确式触摸板，并行报告模式）。在别的触摸板上遇到问题，请附上「设置 → 诊断」生成的诊断报告。
- 程序没有正式的代码签名，第一次运行时 Windows 可能提示「无法验证发布者」。
- 普通权限版在以管理员身份运行的程序在前台时收不到按键（Alt+Tab 交给 Windows），中键也传不到它。
- 切换桌面时 Windows 自己会在屏幕底部弹出桌面名提示，压不掉。

## English

2.1 is about reaching more than Chinese-speaking users: GlideShell's interface, installer package and website are now available in English.

**English interface**
- The settings window, tray menu, notifications, Diagnostics page and diagnostic report come in Simplified Chinese and English.
- By default GlideShell follows your Windows display language: Chinese if Windows is in Chinese, English for everything else.
- You can switch under Settings → Home → 语言 / Language; it applies immediately. The config option is `language` (`auto` / `zh-CN` / `en`).
- The log is always in Chinese.

**New installer package**
- Double-click `Install.cmd` / `Uninstall.cmd`; the bundled `README.txt` is bilingual.
- Install and uninstall messages follow the system language.
- Fixed: the uninstall script used to remove the Start menu shortcut wherever it pointed; now it only removes one that points to the copy being uninstalled.

**Website and guide**
- The website and user guide are now in English: <https://liamzhaofor.github.io/GlideShell/en/>.

**Install or upgrade**
- On 2.0.0: click the update notification or Settings → About → Upgrade. Your settings are kept.
- New install: download `GlideShell-2.1.0-win-x64.zip`, extract it and double-click `Install.cmd` (no administrator rights needed).
- Using a touchpad other than ASUS? Please file a touchpad compatibility report on GitHub, whether it works well or not.

**Known limitations**: only fully verified on one ASUS precision touchpad; not code-signed, so Windows may warn about an unverified publisher on first run; the standard build can't send keys or middle clicks to apps running as administrator.
