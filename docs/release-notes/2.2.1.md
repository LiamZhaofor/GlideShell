2.2.1 是一次小修：卡片圆角更好看，顺带修掉几个烦人的小问题。

## 修正与改进

- **窗口卡片的圆角改成屏幕上固定 16**：原来圆角跟着窗口一起缩小，总览里窗口一般缩到原来的两三成，看上去几乎是直角，而且大小卡片圆得不一样。现在所有卡片一样圆，悬停框、切换条选中框也跟着对齐。
  - 「设置 → 总览与桌面 → 窗口圆角」的滑块现在就是屏幕上的半径，0 = 直角。
  - 配置项改名为 `overview.cardRadius`（默认 16）。旧的 `cornerRadius` 意思不一样了，不再读取；改过它的话，请在设置里重新调一次。
- **圆角边缘不再有锯齿**：窗口卡片、桌面条缩略图、毛玻璃面板的圆角都改成抗锯齿边缘。
- **Alt+Space 搜索框的毛玻璃偶尔缺掉一块**：后面是浏览器、Electron 程序等正在刷新的窗口时，面板里有时会露出一块透明的矩形。现在搜索框开着时毛玻璃整块重画，不会再缺。
- **每次重启或关机后都提示「GlideShell 上次异常退出了」**：其实没有出错，是关机时 GlideShell 被系统结束，被误判成了异常退出。现在关机时 GlideShell 会自己正常退出，不再误报。

## 安装与升级

- 已装 2.0.0 – 2.2.0 的：点托盘的升级通知或「设置 → 关于 → 升级」，一键升级，设置保留。
- 新安装：下载 `GlideShell-2.2.1-win-x64.zip`，解压后双击 `Install.cmd`（不需要管理员权限）。
- 完整的使用教程：<https://liamzhaofor.github.io/GlideShell/guide.html>

## 已知限制

- 只在一台机器上完整验证过（ASUS 精确式触摸板，并行报告模式）。在别的触摸板上遇到问题，请附上「设置 → 诊断」生成的诊断报告。
- 程序没有正式的代码签名，第一次运行时 Windows 可能提示「无法验证发布者」。
- 普通权限版在以管理员身份运行的程序在前台时收不到按键（Alt+Tab、Alt+Space 交给 Windows），中键也传不到它。

## English

2.2.1 is a small polish release.

**Fixes and improvements**
- **Window cards now have a fixed 16 DIP corner radius on screen.** Corners used to shrink with the window, so overview cards looked almost square and cards of different sizes had different corners. The slider under Settings → Overview & desktops → Window corner radius is now the on-screen radius (0 = square). The setting is renamed `overview.cardRadius` (default 16); the old `cornerRadius` is no longer read, so re-adjust it in Settings if you had changed it.
- **Smooth corners**: window cards, desktop thumbnails and frosted-glass panels now have anti-aliased rounded edges.
- **The Alt+Space search panel sometimes lost part of its frosted glass** over browsers and other constantly redrawing windows. The glass is now redrawn as a whole while search is open.
- **“GlideShell exited unexpectedly last time” after every restart or shutdown**: nothing had actually gone wrong; being ended by Windows at shutdown was mistaken for a crash. GlideShell now exits cleanly on its own during shutdown.

**Install or upgrade**
- On 2.0.0 – 2.2.0: click the update notification or Settings → About → Upgrade. Your settings are kept.
- New install: download `GlideShell-2.2.1-win-x64.zip`, extract it and double-click `Install.cmd` (no administrator rights needed).

**Known limitations**: only fully verified on one ASUS precision touchpad; not code-signed, so Windows may warn about an unverified publisher on first run; the standard build can't send keys or middle clicks to apps running as administrator.
