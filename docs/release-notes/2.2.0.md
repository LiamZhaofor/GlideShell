2.2 的主题是「在总览里把事情做完」：后台程序和要打开的程序，都不用再去任务栏和开始菜单找。

## 后台程序栏

- 三指上滑打开总览，底部会列出托盘里的后台程序（没有可见窗口的那些，比如微信、QQ、各种工具）。
- 点一下和单击托盘图标一样。程序打开了窗口的话，窗口会从图标处长大、飞到它的位置，同时总览收起。
- 右键直接在总览里、鼠标旁边弹出这个程序的托盘菜单，不用先收起总览。菜单里选了「退出」，它会从栏里淡出。
- 不想看到的程序可以在「设置 → 总览与桌面 → 选择显示哪些程序」里隐藏；整栏不要的话关掉「底部显示后台程序」。配置文件里对应 `overview.trayApps`、`overview.hiddenTrayApps`。

## 程序搜索

- 总览打开时直接打字就能搜开始菜单里的程序，Enter 打开。拼音全拼、首字母、英文单词开头都能找到：`wx`、`weixin` → 微信，`vsc` → Visual Studio Code，`jsq` → 计算器。
- 常用的程序排在前面。↑↓ / Tab 选择，Esc 回到窗口；鼠标移上去选中，点一下打开。
- **在任何地方按 Alt+Space** 都能单独弹出搜索框（不进总览），再按一次或 Esc 收起。没输入时列出最近从这里打开过的程序，最近的在最上面。
  - 快捷键可以在「设置 → 总览与桌面 → 打开搜索的快捷键」里改成别的组合，或者清空不用（配置 `overview.searchHotkey`）。
  - 注意：Alt+Space 原本是 Windows 打开窗口菜单（还原、移动、最小化……）的快捷键，用了这个功能后它归 GlideShell。需要窗口菜单的话，把搜索换成别的快捷键。
  - 前台是全屏游戏或视频时不响应，按键照常交给它。
- 开始菜单里没有的程序，可以在「设置 → 总览与桌面 → 手动添加的程序」里点「浏览…」加进来（exe、快捷方式、批处理都行），之后同样能搜到、打开（配置 `overview.searchExtraApps`）。
- 整个搜索功能（包括快捷键）可以在「设置 → 总览与桌面 → 打字搜索程序」里关掉（配置 `overview.search`）。

## 修正与改进

- 总览有时把窗口排成一横排，每个缩得很小。现在会比较各种行数，选窗口最大的排法。
- 三指左右滑后没有切换窗口（停在或滑回当前窗口）时，当前窗口不会再从切换条飞回一次，切换条直接淡出。
- 升级到 .NET 10.0.14，包含微软 2026 年 10 月的安全修复。

## 安装与升级

- 已装 2.0.0 或 2.1.0 的：点托盘的升级通知或「设置 → 关于 → 升级」，一键升级，设置保留。
- 新安装：下载 `GlideShell-2.2.0-win-x64.zip`，解压后双击 `Install.cmd`（不需要管理员权限）。
- 完整的使用教程：<https://liamzhaofor.github.io/GlideShell/guide.html>

## 已知限制

- 只在一台机器上完整验证过（ASUS 精确式触摸板，并行报告模式）。在别的触摸板上遇到问题，请附上「设置 → 诊断」生成的诊断报告。
- 程序没有正式的代码签名，第一次运行时 Windows 可能提示「无法验证发布者」。
- 普通权限版在以管理员身份运行的程序在前台时收不到按键（Alt+Tab、Alt+Space 交给 Windows），中键也传不到它。
- 少数程序的托盘菜单认不出来时，总览会先收起，菜单照常出现在程序自己定的位置。

## English

2.2 is about getting things done from the overview: no more hunting through the taskbar tray or the Start menu.

**Background apps bar**
- The overview now lists your tray apps (apps with no visible window) along the bottom.
- Click one to do what clicking its tray icon does; if it opens a window, the window grows out of the icon into place.
- Right-click shows the app's tray menu right there in the overview, next to the pointer. Apps you quit disappear from the bar.
- Hide apps under Settings → Overview & desktops → Choose which apps to show, or turn the bar off with “Show background apps at the bottom” (`overview.trayApps`, `overview.hiddenTrayApps`).

**App search**
- With the overview open, just start typing to search Start menu apps and press Enter to open one. Word starts and Chinese pinyin (full or initials) both work, e.g. `vsc` → Visual Studio Code.
- **Press Alt+Space anywhere** to open search on its own, without the overview. With nothing typed it lists the apps you opened from it, most recent first.
  - Change or clear the shortcut under Settings → Overview & desktops (`overview.searchHotkey`). Alt+Space normally opens the window menu in Windows; pick another shortcut if you need that.
  - It does nothing while a fullscreen game or video is in front.
- Add programs that aren't in the Start menu under Settings → Overview & desktops → Apps added by hand (`overview.searchExtraApps`).

**Fixes**
- The overview sometimes laid windows out in a single tiny row; it now picks the row count that keeps windows largest.
- After a three-finger sideways swipe that ends on the current window, the switcher now just fades out instead of replaying the fly-back animation.
- Updated to .NET 10.0.14 with Microsoft's October 2026 security fixes.

**Install or upgrade**
- On 2.0.0 or 2.1.0: click the update notification or Settings → About → Upgrade. Your settings are kept.
- New install: download `GlideShell-2.2.0-win-x64.zip`, extract it and double-click `Install.cmd` (no administrator rights needed).

**Known limitations**: only fully verified on one ASUS precision touchpad; not code-signed, so Windows may warn about an unverified publisher on first run; the standard build can't send keys or middle clicks to apps running as administrator.
